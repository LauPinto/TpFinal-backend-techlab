# 🧙 Tienda Medieval - Backend en Java Spring Boot

Este proyecto es una API REST desarrollada con Spring Boot, que permite gestionar productos y realizar pedidos en una tienda medieval ficticia. La aplicación usa una base de datos en memoria H2 y permite realizar operaciones CRUD de productos y generación de pedidos con detalle y fecha.

## 📦 Funcionalidades principales

### 🔹 Productos
- Crear, listar, actualizar y eliminar productos.
- Consultar productos por ID o por nombre.
- Actualizar stock de forma parcial.

### 🔹 Pedidos
- Crear pedidos seleccionando múltiples productos con cantidades.
- Calcular total del pedido.
- Devolver detalle del pedido con fecha, productos, cantidades y subtotales.
- Listar todos los pedidos generados.

## ⚙️ Tecnologías utilizadas

- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA
- H2 Database
- Maven
- Insomnia/REST Client para pruebas
